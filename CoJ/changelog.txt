 CoJ2 Controller - IranCoJ Edition
 Version 3.4.0.0  -  2026-10-05
 Fork of the original CoJ2 Controller by S!lv3r and Tr!tu (GPLv3).
===============================================================================

This update adds the IranCoJ New Classes (Rancher and Redneck) and their
weapons to the class modding, and fixes setting a mod on a server whose
CoJ2\Data\Player folder already holds other files.

-------------------------------------------------------------------------------
 NEW FEATURES
-------------------------------------------------------------------------------

* Rancher and Redneck in the class modding: they are in the class list, the
  "Add class" picker (with their own pictures) and the "Look Mod" table, and
  a new mod includes them like the other classes. Their default weapons:
    - Rancher: two Border Guns + Throwing Knives
    - Redneck: Springfield Musket + Tomahawks

* New weapons, with side-view pictures:
    - Left / right hand: Border Gun, Throwing Knives, Tomahawks
    - Both hands: Springfield Musket, Throwing Knives, Tomahawks
  The knives and tomahawks bring their own throws (5 / 3), no ammo needed.
  They need the IranCoJ New Classes mod on the server and the players' games.

-------------------------------------------------------------------------------
 BUG FIXES
-------------------------------------------------------------------------------

* "Set this mod ingame" and "Restore original classes in game" no longer
  delete the whole CoJ2\Data\Player folder. When the folder held other files
  (for example a Docker volume with the New Classes' scripts) they failed with
  an unhandled "directory is not empty" error - and when they worked they
  deleted those files. Now only the
  class weapon files (_NetWeapon_<class>_Properties.scr) are taken out and the
  mod's files are copied over, replacing any with the same name. Rancher and
  Redneck get their New Classes weapons back unless the mod sets them.

* The "Look Mod" table showed the wrong ammo for the three biggest amounts
  (85 / 95 / 100 instead of the 95 / 140 / 190 the mod really gives).

-------------------------------------------------------------------------------
 NOTES
-------------------------------------------------------------------------------

* Mods saved by older versions load as before. A mod that uses the new weapons
  stores them as letters (A, B) in its mod.ini, which older Controllers can't
  read.

 CoJ2 Controller - IranCoJ Edition
 Version 3.3.2.0  -  2026-09-28
 Fork of the original CoJ2 Controller by S!lv3r and Tr!tu (GPLv3).
===============================================================================

This update adds bot controls and a whitelist-only "protect" mode against a
cheater who keeps changing IP and name, and fixes map modes being saved as
"<wanted>" by "Remember last maps".

-------------------------------------------------------------------------------
 NEW FEATURES
-------------------------------------------------------------------------------

* !deploybot <N> / !removebot  (NEW admin commands)
    !deploybot 4 sends /deploybot 4 to the server; N must be a whole number
    above 0, otherwise the usage hint is shown. !removebot sends /removebot.
    Admin-only, no toggle.

* !protect  (NEW admin command) - whitelist-only server
    For a player who dodges IP bans by changing IP and name. While protect is
    ON, anyone who joins with a name that is not in the whitelist is kicked at
    once ("Not on the whitelist").
      !protect on       Turn on (also kicks non-whitelisted players already in).
      !protect off      Turn off.
      !protect          Show whether protect is on, plus the usage.
    - Whitelist: "whitelist.txt" next to the exe, one name per line. Blank
      lines and lines starting with # are ignored. The file is re-read on every
      check, so it can be edited while the server runs.
    - Names must match exactly, including capital letters.
    - Admins are never kicked by protect.
    - Protect will not turn on while whitelist.txt is missing or empty, and if
      the file disappears while it is on, nobody is kicked - a bad file can never
      empty the server.
    - The on/off state is remembered across controller restarts.

-------------------------------------------------------------------------------
 CHANGES
-------------------------------------------------------------------------------

* The admin !commandlist is more compact so the whole list fits in CoJ chat's
  3-line limit even with every command enabled: argument hints were dropped,
  the separator was shortened, the four music commands are shown as
  "!play/stop/skip/shufflemusic", and !commandlist no longer lists itself.

* Usage hints: typing an admin command without its arguments now replies with
  the arguments it takes, e.g. "!kick" -> "Usage: kick <name/id>". Covers
  !kick, !ban, !unban, !kill, !newadmin, !adminsay, !mapgo, !addword,
  !balance, !deploybot, !protect and !votekick. Previously most of these did
  nothing at all when typed bare. (The hint is shown without the "!" so the
  controller can't mistake its own echoed reply for a new command.)

-------------------------------------------------------------------------------
 BUG FIXES
-------------------------------------------------------------------------------

* Typing "!addword" with no word no longer causes an error in the console
  reader; it shows the usage hint instead.

* "Remember last maps" no longer saves modes wrapped in brackets. A plain mode
  such as "wanted" was written to DedicatedServerSettings.ini as "<wanted>".
  A file already saved that way is repaired automatically the next time the
  controller loads it, and stray extra Map() lines beyond the rotation are
  dropped when the rotation is saved.

-------------------------------------------------------------------------------
 NOTES
-------------------------------------------------------------------------------

* Protect matches names only. Someone joining under a whitelisted name, or
  renaming with /nick after joining (which the console never reports), is not
  caught - keep using IP bans alongside it.

* If bots are deployed while protect is on, add the bot names to
  whitelist.txt or they will be kicked like any other unlisted name.

 CoJ2 Controller - IranCoJ Edition
 Version 3.3.1.0  -  2026-08-31
 Fork of the original CoJ2 Controller by S!lv3r and Tr!tu (GPLv3).
===============================================================================

This update adds a music-shuffle command and closes a vote-fraud hole where
renaming let a player vote repeatedly.

-------------------------------------------------------------------------------
 NEW FEATURES
-------------------------------------------------------------------------------

* !shufflemusic  (NEW admin command)
    Shuffles the VoiceChat mod's music folder. Admin-only, no toggle; writes
    "shuffle" to music_cmd.txt like the other music commands, and is listed in
    !commandlist.

-------------------------------------------------------------------------------
 BUG FIXES
-------------------------------------------------------------------------------

* Votes are now counted per unique player id, not per name. A player could
  previously vote as many times as they liked by changing name with /nick
  (which prints nothing to the console, so the old name-based tally never saw
  it as the same player). Votes are now tracked by the player's unique id, and
  the roster is refreshed when a vote starts. If a name cannot be matched to a
  current id (e.g. after a /nick the controller never saw), that vote is
  ignored rather than counted - closing the exploit in the safe direction.

* !commandlist no longer runs off the end of the last line for admins. CoJ
  chat shows at most 3 lines, and the admin list had grown past them once the
  music commands were added; the longest argument hints (!mapgo, !votemapgo,
  !playmusic) were shortened in the admin list so everything fits. The commands
  still accept the same arguments.

-------------------------------------------------------------------------------
 NOTES
-------------------------------------------------------------------------------

* A player who renames mid-game with /nick will not be recognised for votes (or
  admin commands) under the new name until the controller sees that name mapped
  to an id - normally on their next reconnect. This is intentional: /nick is
  invisible to the controller, so tying identity to the unique id is what makes
  the vote counting spoof-proof.

 CoJ2 Controller - IranCoJ Edition
 Version 3.3.0.0  -  2026-08-23
 Fork of the original CoJ2 Controller by S!lv3r and Tr!tu (GPLv3).
===============================================================================

This update adds admin music-stream controls that drive the IranCoJ VoiceChat
mod's music player from in-game chat, by writing to a command file the relay
watches.

-------------------------------------------------------------------------------
 NEW FEATURES
-------------------------------------------------------------------------------

* Music stream commands (NEW admin commands)
    Control the VoiceChat mod's music player straight from in-game chat. The
    controller writes the command to a "music_cmd.txt" file that the VoiceChat
    relay watches and acts on. Admin-only; no on/off toggle; listed in
    !commandlist.
      !playmusic <song>          Play a track once. Type just the name (no
                                 extension); ".mp3" is added. e.g. !playmusic 1
      !playmusic <song> loop     Play that track on repeat.
      !playmusic                 (no arguments) play the whole music folder.
      !stopmusic                 Stop playback.
      !skipmusic                 Skip to the next track (in folder mode).
    - Mount music_cmd.txt into the controller's own folder (next to the exe);
      the same host file is mounted into the VoiceChat relay container so a
      write from the controller is picked up by the relay.
    - Writes are atomic (temp file + rename) so the relay never reads a
      half-written command; the exact command line the relay expects is written
      verbatim (play/loop/folder/skip/stop), with no extra tokens.

-------------------------------------------------------------------------------
 BUG FIXES
-------------------------------------------------------------------------------

* Fixed a build-time ambiguity ("'Text' is ambiguous") on the plain .NET
  Framework 4.0 toolchain by fully qualifying two System.Text references. No
  behaviour change; the shipped program is unaffected.

-------------------------------------------------------------------------------
 NOTES
-------------------------------------------------------------------------------

* If the relay stops seeing updates, mount the containing FOLDER rather than the
  single music_cmd.txt file - a single-file bind mount can pin the old inode so
  a rename over it is not seen inside the container.

 CoJ2 Controller - IranCoJ Edition
 Version 3.2.0.0  -  2026-08-16
 Fork of the original CoJ2 Controller by S!lv3r and Tr!tu (GPLv3).
===============================================================================

This update adds a player-voted instant map jump and turns !ban into a real
permanent ban that is separate from the temporary auto-kick.

-------------------------------------------------------------------------------
 NEW FEATURES
-------------------------------------------------------------------------------

* !votemapgo <map> <mode>  (NEW public command)
    Lets players start a vote to jump straight to a specific map, the voted
    equivalent of the admin !mapgo. When the vote passes, the controller
    performs the exact same map jump !mapgo does.
    - Has its own on/off toggle in "Commands for all players" ("!votemapgo").
    - The target map/mode is validated when the vote STARTS, so a bad map name
      is rejected up front instead of failing silently after the vote.

* !ban is now a real PERMANENT ban (separate from auto-kick)
    !ban <name/id> now keeps a player out for good, not just the 5-minute
    auto-kick window that !kick uses.
    - !ban <name/id>   Kicks the player and adds them to the controller's ban
                       list; every time they rejoin they are kicked again, with
                       the message "Permanently banned - appeal at IranCoJ".
    - !unban <name>    Removes a player from the ban list.
    - Both !kick and !ban issue the game's /kick (the game has no native ban);
      the difference is bookkeeping: a banned player is excluded from the
      5-minute auto-kick and blocked on every rejoin instead.

-------------------------------------------------------------------------------
 BUG FIXES
-------------------------------------------------------------------------------

* !vote no is now counted. Previously only "!vote yes" was tallied for
  !votemapnext, !votemapgo and !votekick; a "no" majority now ends the vote
  immediately as not passed.

* Fixed vote counting getting corrupted after a failed vote. A failed
  !votemapgo could leave a phantom "0/0" vote active that broke the next
  !votemapnext; votes now only start once fully validated.

 CoJ2 Controller - IranCoJ Edition
 Version 3.1.0.0  -  2026-07-27
 Fork of the original CoJ2 Controller by S!lv3r and Tr!tu (GPLv3).
===============================================================================

This update makes admin authorization spoof-proof: admin ! commands are now
granted by real in-game /adminlogin authentication (via a bundled server mod)
instead of by matching a typed player name, and it fixes the map rotation
getting out of sync when maps are changed outside of !mapgo.

-------------------------------------------------------------------------------
 NEW FEATURES
-------------------------------------------------------------------------------

* Authenticated admins (no more name spoofing)
    Admin ! commands are now authorized by whoever has actually logged in with
    /adminlogin in-game, not by matching the (spoofable) player name against the
    Admins list. Naming yourself after an admin no longer grants any command.
    - Authentication is done by the bundled server mod (version.dll), which
      validates /adminlogin against the server's ServerAdmins.ini and publishes
      the currently-authenticated admins to "authed_admins.txt".
    - The manual Admins list still works as a FALLBACK when the mod is not
      loaded, so nothing breaks on servers without the mod.
    - The same check now also exempts real admins from the bad-word filter and
      protects them from being !votekick'd.
    - An admin's authorization is revoked the moment they leave or are kicked,
      so a new player reusing their name cannot inherit it.

* Bundled admin mod, auto-deployed
    The version.dll admin mod now ships inside the single .exe and is copied
    into your dedicated-server folder automatically the first time you point the
    controller at it - no manual install. (Under Wine, launch the controller
    with WINEDLLOVERRIDES="version=n,b" so the server loads it.)

-------------------------------------------------------------------------------
 CHANGES
-------------------------------------------------------------------------------

* !commandlist now shows the full admin command list to authenticated admins and
  only the public commands to everyone else, driven by the same authentication.

-------------------------------------------------------------------------------
 BUG FIXES
-------------------------------------------------------------------------------

* Fixed the map rotation getting out of sync. The controller now reads which map
  the server actually loaded (from the "Loading map <...>" line) and realigns its
  tracked rotation to it. Changing maps with /mapset from the bare console (or via
  the in-game mod) no longer leaves the controller a step behind; !mapgo and
  /mapset can be used together without conflict.

-------------------------------------------------------------------------------
 NOTES
-------------------------------------------------------------------------------

* Supersedes the 3.0.0.0 note about admins: /adminlogin is now recognised (via
  the mod). Adding names to the Admins list is only needed as a fallback for
  servers that do not run the mod.

* The mod is unpacked to a "mod" subfolder next to the exe and copied from there
  into the server folder, so it is never loaded into the controller itself.

===============================================================================
 Version 3.0.0.1  -  2026-07-26
===============================================================================

* Single-exe compatibility fix: the embedded payload was changed from a ZIP
  (which needs System.IO.Compression, only present on .NET 4.6+) to a simple
  uncompressed container read with plain System.IO. The single .exe again runs
  on .NET Framework 4.0 - e.g. under Wine with dotnet40 - like earlier versions.

 CoJ2 Controller - IranCoJ Edition
 Version 3.0.0.0  -  2026-07-25
 Fork of the original CoJ2 Controller by S!lv3r and Tr!tu (GPLv3).
===============================================================================

This is a major update. Highlights: a new instant map-jump command, automatic
recovery when the dedicated server crashes, auto-kick for recently kicked
players, a new western-themed interface, and distribution as a single .exe that
unpacks everything it needs on first run.

-------------------------------------------------------------------------------
 NEW FEATURES
-------------------------------------------------------------------------------

* !mapgo <map> <mode>  (NEW admin command)
    Jump straight to any map in the rotation instead of pressing "next" over and
    over. Type, for example:  !mapgo tombstone manhunt
    - Admin-only.
    - Has its own on/off toggle on the Admins page ("!mapgo").
    - Listed in !commandlist when enabled.
    - When "Remember last maps" is enabled, the rotation is kept in sync so the
      chosen map becomes the new head of the cycle.

* Automatic server crash recovery
    If the dedicated server process closes unexpectedly while the console is
    open, the controller now relaunches it and re-attaches automatically.
    - New "Auto-restart" checkbox on the Chat page (on by default).
    - It will NOT interfere with an intentional admin Shutdown or Restart.
    - Logs "Dedicated server crashed - auto-restarting..." to the console.

* Auto-kick returning players (5 minutes)
    When a player is kicked - by an admin's in-game /kick OR by a passed
    !votekick - they are kept out for 5 minutes: if they rejoin within that
    time the controller kicks them again automatically and tells them how long
    is left. The 5 minutes count from the first kick.
    - New "Auto-kick (5m)" checkbox on the Chat page (on by default).

* Single-exe distribution
    The whole program now ships as ONE file: CoJ2Controller.exe.
    - On first run it unpacks the images, mod files and help file next to
      itself automatically - no separate folders to copy.
    - If it is placed in a read-only/protected location (e.g. Program Files)
      it now shows a clear warning telling you to move it to a writable folder.

* Western-themed interface
    - Main window: wood/leather themed image buttons and a new background.
    - Admin console: aged-wood / parchment / brass color scheme, themed tabs,
      map grid and inputs.

-------------------------------------------------------------------------------
 CHANGES
-------------------------------------------------------------------------------

* !maplist now shows the next 3 maps (previously only 2).

* !votemapnext now passes on a simple majority - more than half of the players
  must vote yes (previously required ~76%). Now consistent with !votekick.

* !votekick now requires a simple majority (more than half of the players) and
  its "player not found" handling is clearer.

* The console window is now a fixed size and can no longer be resized, which
  fixes controls being stretched or pushed off the edges.

-------------------------------------------------------------------------------
 BUG FIXES
-------------------------------------------------------------------------------

* Fixed a crash ("Argument 'Length' must be greater or equal to zero") that
  happened when !votekick or !voteban was typed without a player name.

* Fixed several console layout problems: the Help (F1) button overlapping the
  Rules tab, the !mapgo toggle being hidden, the map grid missing its right-hand
  border and misaligned column headers, and buttons/boxes being cut off at the
  bottom on the Chat, Players, Admins, Logs and Rules pages.

* Fixed the main-window background being stretched/distorted.

-------------------------------------------------------------------------------
 REMOVED
-------------------------------------------------------------------------------

* !voteban has been removed (bans are handled outside this tool). The command
  no longer does anything and is no longer shown in the command list.

* Removed 43 unused image files, making the download smaller.

* Removed the dead http://coj2controller.hol.es link and replaced the broken
  "Custom maps" download with the current IranCoJ launcher page on ModDB.

-------------------------------------------------------------------------------
 NOTES
-------------------------------------------------------------------------------

* Admins are recognised by name from the Admins list in the controller. The
  in-game /adminlogin command is handled by the dedicated server itself and is
  not visible to the controller, so an admin must be present in the list to use
  the admin ! commands.

* Requires .NET Framework 4.8 (already included in Windows 10 and 11).

* Put the exe in a normal, writable folder (Desktop, Documents, a games/tools
  folder) - not inside Program Files.
